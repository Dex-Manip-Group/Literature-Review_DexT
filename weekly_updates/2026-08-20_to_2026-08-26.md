## 1. 更新结论

本周有两个变化会直接影响 BiCG/结构化触觉表示的实验设计。

1. **预测式触觉表示正在从“未来触觉重建”走向有方向的物理层级。**
   HiTac-WAM 明确把 contact state、3D deformation 和 slip risk 按有向依赖关系组织起来，
   并把预测误差用于在线重规划。这使“分层预测头是否优于同预算扁平 latent”成为必须加入
   的比较，而不是可选消融。
2. **时序视觉—触觉表征基线明显增强。** VT-MUSE 用跨模态时序对齐、masked-view
   consistency 和带训练期 privileged posterior 的条件变分目标学习 frozen sequential
   representation。后续若只与简单 concat 或普通 ACT 比较，已经不足以支撑结构优势。

另外三条趋势值得纳入设计：

- ViTacPhys 把质量、摩擦和刚度显式作为可迁移的物理属性；这些属性可作为 BiCG 的辅助头
  或分层诊断目标，但不能替代跨界面载荷路径。
- SoftVTBench 把任务成功与峰值形变联合成 DSR，说明“完成任务但损伤/过载”应单独计量。
- 双手方向的新工作主要加强视觉几何、VLA 和缺失模态鲁棒性，仍未直接解决部署可见触觉
  下的跨手动态载荷拓扑。

**本轮判断：** 在这批当周论文中，没有一篇同时覆盖“双手 + 分布式触觉 + 从部署观测
推断手—物—工具/工件动态关系 + topology OOD”。这只是本轮筛查结论，不应扩写成全领域
的首次或唯一性声明。

## 2. 纳入活文献库的 10 篇论文

### A. 直接影响核心表示与基线

#### HiTac-WAM

- 入口：[arXiv 2608.19574](https://arxiv.org/abs/2608.19574)
- 方法：先预测 contact state，再预测 3D deformation，最后预测 slip risk；使用 stop-gradient
  固定有向层级，并对候选 action chunk 排序。执行时保留所选触觉预测作参考，观测偏离时重规划。
- 论文报告：contact F1 为 0.921；在匹配预算下，相对 deformation-only，形变 L2 误差下降
  17.6%；相对 slip-only，slip AUPRC 提升 60.4%。三项真实任务中，动作选择成功率由
  31.1% 提升到 61.1%，完整系统为 72.2%。
- 边界：单夹爪、双 DM-Tac 传感器，不是双手系统级 contact graph。
- 对本项目的动作：加入 **flat multi-head vs directed hierarchy**、有/无 stop-gradient、
  预测误差触发重规划三组消融。

#### VT-MUSE

- 入口：[arXiv 2608.21290](https://arxiv.org/abs/2608.21290)
- 方法：第一阶段做跨模态时序对齐与 masked-view consistency；第二阶段用视觉历史和完整
  触觉历史构造训练期 posterior，同时学习部署可用 prior，并预测触觉深度变化。
- 论文报告：四项 UniVTAC 仿真任务平均成功率 55.25%，对照 ACT+UniVTAC 为 39%；
  四项真实任务共 80 次试验报告 95%，其 visuotactile ACT 对照为 31.25%。
- 边界：左右触觉 RGB 在编码前做空间拼接，没有显式保留 hand/interface identity；
  论文摘录中未见多随机种子或显著性检验。
- 对本项目的动作：将其作为 **frozen sequential visuotactile encoder** 强基线，并与显式
  hand/finger/interface tokenization 做等预算比较。

### B. 物理属性、局部事件与硬件

#### ViTacPhys

- 入口：[arXiv 2608.21355](https://arxiv.org/abs/2608.21355)；
  [项目页](https://vitacphys.github.io/ViTacPhys/)
- 数据与方法：60 个物体、1,800 条人类示范；从时序视觉—触觉信号估计质量类别、摩擦类别
  和连续刚度，再进行 human-to-robot policy transfer。
- 论文报告：held-out object 上质量准确率 87.5%、摩擦准确率 97.5%、刚度 MAPE 9.08；
  策略成功率为 ID 95%、OOD 83.4%。
- Artifact：截至本轮筛查，项目页的 Code 和 Dataset 均标为 “Coming Soon”。
- 对本项目的动作：把 friction/stiffness 作为独立 probe；避免将 VLM 语义先验误当作触觉
  物理辨识本身的证据。

#### Robust Slip Detection and Material Classification

- 入口：[arXiv 2608.24162](https://arxiv.org/abs/2608.24162)
- 方法：新型均匀照明视觉触觉传感器，加双头 TimeSformer；数据覆盖 15 个物体并记录深度。
- 论文报告：未见物体上三类 contact state 准确率 95.5%，八类 slip direction 准确率
  91.5%；静态物体分类为 98.8%。
- 对本项目的动作：可作为局部 slip/contact head 基线，但不能作为跨手结构模型的替代。

#### A Durable Vision-Based Tactile Fingertip

- 入口：[arXiv 2608.24242](https://arxiv.org/abs/2608.24242)
- 贡献：可替换 sensing cartridge，重点解决视觉触觉指尖在真实操作中的耐久与维护问题；
  论文按其测试口径报告相对 GelSight Mini 和 DIGIT 超过两个数量级的耐久提升。
- 对本项目的动作：对清洗、刷擦等高磨损任务有工程价值；暂不改变表示层新颖性判断。

### C. 接触结构、双手鲁棒性与几何

#### One-Shot Learning by Identifying Physical Interactions

- 入口：[arXiv 2608.24741](https://arxiv.org/abs/2608.24741)
- 方法：从一次示范中显式识别建立/断开接触等物理交互，使用 hybrid position-force
  controller 和 contact-based transition conditions。
- 实验：门锁开启、螺栓拾取/旋入、脱离和表面轮廓跟随。
- 对本项目的动作：作为可解释的 **contact-event state machine** 基线，检验学习到的动态图
  是否真正优于示范中显式提取的接触阶段。

#### CoToGrasp

- 入口：[arXiv 2608.19776](https://arxiv.org/abs/2608.19776)
- 方法：在 object-agnostic canonical workspace 中按目标 contact topology 条件化生成
  dexterous grasp，并在未见物体上做 zero-shot transfer。
- 术语边界：这里的 “contact topology” 是**预先指定的抓取接触布局**；本项目讨论的是
  由部署观测推断、随时间变化、可跨手/工具传播载荷的系统级关系。两者必须分开引用。

#### Robust Bimanual VLA via Modality Masking

- 入口：[arXiv 2608.22419](https://arxiv.org/abs/2608.22419)
- 方法：训练期随机遮蔽视觉、语言、proprioception 和 action query，提升双手 VLA 在模态
  缺失或扰动下的鲁棒性。
- 论文报告：相对 Adapter，RoboTwin 2.0 十项任务的 Clean 提升 21.7 个百分点、
  Clean2Rand 提升 11.4 个百分点；三项真实长程任务的完整任务成功率提升超过 30 个百分点。
- 对本项目的动作：把 **sensor/hand dropout 与 quality mask** 加入训练和压力测试；它不是
  触觉表示方法，但会成为“传感器掉线鲁棒性”的强方法学基线。

#### PartialBiGrasp

- 入口：[arXiv 2608.19188](https://arxiv.org/abs/2608.19188)
- 方法：从 partial point cloud 推断被遮挡局部几何，再搜索满足 bimanual force closure
  的抓取对，并做采样式 refinement。
- 对本项目的动作：作为“视觉几何 + force-closure”双手基线；它能解释一部分双手成功，
  因而触觉方法必须在遮挡、载荷变化或滑移扰动上给出额外收益。

### D. 数据集与评价

#### SoftVTBench

- 入口：[arXiv 2608.18701](https://arxiv.org/abs/2608.18701)；
  [代码仓库](https://github.com/TuojingAI/SoftVTBench)
- 论文版本：报告 4,000 条专家示范、50 余个 assets；记录多视角 RGB、双指触觉 RGB/
  marker motion、proprioception、语言、动作和 evaluator-only FEM state。
- 指标：DSR 同时要求任务成功和峰值归一化形变不超阈值；论文称 12 个 ID 配置中都出现过
  “任务成功但形变超限”的 rollout。分布偏移下，触觉在六组 policy 比较中全部提升 task
  success，并在五组中提升 DSR。
- Artifact 风险：截至本轮筛查，仓库 README 仍写 1,628 条示范、33 个 assets，并指向
  不同/较早的 arXiv 编号；与论文当前版本不一致。复现实验前必须核对实际 release。
- 对本项目的动作：为刷擦/持续接触任务增加“任务成功 + 峰值载荷/形变/滑移约束”的联合
  安全指标，不只报最终 success。

## 3. 观察名单：本轮不计入主语料

- [Fast Coordinated Bimanual Motion Planning With Hard Constraints](https://arxiv.org/abs/2608.20946)：
  固定末端相对变换的 leader–follower 规划，报告 19.4 倍规划加速；属于有用的双手规划
  背景，但没有触觉或表示学习主张。
- [The Missing Touch](https://arxiv.org/abs/2608.19372)：空间分布触觉反馈的人类遥操作研究，
  报告轨迹偏差相对自然示范下降 29%–79%；可用于讨论示范质量，但按当前 protocol 的
  “纯 haptic display/telepresence”边界不进入 study-level synthesis。

## 4. 对现有研究计划的具体修订

### 必增基线

1. VT-MUSE 风格 frozen sequential visuotactile representation。
2. HiTac-WAM 风格 contact → deformation → slip 有向预测层级。
3. 同参数量 flat multi-head、无层级依赖、打乱层级三项 matched controls。
4. contact-event hybrid state machine，区分“可手工定义的阶段结构”和“必须学习的关系”。
5. modality masking / single-hand dropout / tactile quality-mask 训练基线。

### 必增标签或诊断量

- contact state、slip risk/direction、局部 deformation；
- friction/stiffness probe；
- hand/interface identity 和关系变化时间；
- 任务成功之外的峰值载荷、形变、滑移超限与重规划次数。

### 仍未被本周工作关闭的核心缺口

- 双手同时承载阶段的独立 load-share / wrench-transfer 证据；
- 从 raw deployable observations 推断跨手、物体、工具、工件关系；
- 训练未见 participant/edge structure 的严格 topology OOD；
- inferred graph 与 oracle/static/random/shuffled graph 的等预算因果比较。
