# 30 篇核心论文精标综合结论

核验日期：2026-08-14。主表中的每条判断均对应独立证据卡；`NR` 表示全文未报告，而不是否定性结果。

## 1. 竞争版图

30 篇论文并没有形成一个单一的“BiCG 已被做过”结论，而是分别占据了六类位置：

1. **强策略与融合基线**：T-Rex、ViTacFormer、FTP-1、TAMEn、VTDexManip 已使“把触觉加入双手策略”本身不再新颖。
2. **图与关系表征**：PhysGraph、TouchWGNN、TacGNN、RoboPack 已覆盖 link graph、taxel graph、层级手图和粒子动力学图；因此不能把“用了 GNN/动态图”作为主要贡献。
3. **空间/接触锚定**：SaTA、Contact-Anchored Policies、Neural/Semantic Contact Fields 已覆盖 FK 空间锚、接触坐标系和连续接触场；因此不能把“对象坐标触觉”作为唯一创新。
4. **物理目标与控制**：Handover Control、Tactile Tool Manipulation、ContactNets、Extrinsic Contact Mode Control 给出了载荷转移、准静态平衡、互补/摩擦和接触模式的可验证目标。
5. **跨传感器/形态表征**：Sparsh、T-Dex、AnyTouch、HTT、TactAlign、FTP-1 已覆盖局部触觉 SSL、异构传感器 token 和人到机器人对齐。
6. **任务与 benchmark**：Bimanual Taxonomy、BUDS、Bi-DexHands、TACO、TactiDex 定义了物理耦合、固定角色、组合 OOD、全手触觉指标和大规模任务空间。

精标后仍然明确空缺的是：**从部署可用的双手触觉、本体与可选视觉中推断跨手/工具接口的分层动态边，并用载荷、未来界面 wrench、接触转移和跨拓扑迁移来验证这些边是否有用。**

## 2. 对 BiCG-Rep 的结论

BiCG encoder 仍有研究意义，但需要把“图”降为假设，把贡献放在以下四点：

- **观测可实现性**：推理时不能使用仿真 contact graph、完整对象状态、未来参考或目标触觉序列。
- **跨接口层级**：局部 taxel/finger 节点之上，显式建模 hand--object--hand 和 hand--tool--workpiece--hand 的界面边。
- **力学可证伪目标**：future edge、load share、100--300 ms interface wrench、slip risk、force-balance residual 与 uncertainty；估计 wrench 不写成独立真值。
- **跨拓扑验证**：handover 训练/探针后迁移到工具--工件结构；必须与相同局部 encoder、模态和参数预算的 Transformer、cross-attention、SaTA-like、static graph、TouchWGNN-like 和 oracle graph 比较。

因此，建议论文表述是：**observation-grounded dynamic bimanual contact-flow representation**，而不是“first bimanual tactile graph”。

## 3. 现阶段先做什么

### Go 路线

1. **数据审计**：优先 T-Rex 公共数据（若下载项完整）和 VTDexManip Bimanual Hand-over；按 episode/object/contact-sequence 拆分，禁止 frame-level 泄漏。
2. **局部 encoder 固定**：图像触觉用 Sparsh/HTT 类冻结 backbone；力/阵列触觉用共享 temporal encoder。所有系统级基线共享同一 encoder。
3. **离线最小任务**：contact phase、future edge、load share、future wrench、slip risk。先不训练大 VLA 或全套端到端策略。
4. **强基线**：proprio-only、concat、cross-attention、temporal Transformer、SaTA-like、static graph、TouchWGNN-like dynamic taxel graph、inferred BiCG、oracle graph。
5. **Go 门槛**：3 seeds 内部判断；正式 5 seeds。transition macro-F1 约 +5 pp，或 load-share MAE 相对 -15%；inferred graph 保留约 70% oracle 增益。

### Pivot 路线

若 inferred graph 无法超过 matched-budget temporal/cross-attention，但 oracle graph 明显有效，转向 **privileged-to-observation graph distillation**；TactAlign 的 pseudo-pair/对齐思路和仿真 contact graph 可作为教师，但学生推理只使用部署观测。

若 oracle graph 也无稳定增益，则停止“graph encoder 是主贡献”的主张，转向 **BiLoadBench/contact-inference benchmark** 或物理目标/标注协议论文。

## 4. 工具协同何时加入

工具协同与主线高度相近，但工具使用本身已是成熟研究主题，而不是“less crowded”类别：PhysGraph、TAMEn、TACO、Semantic Contact Fields、BUDS 等都构成邻近或直接竞争。相对稀疏的是部署可观测条件下、带 matched baselines 的跨手载荷流与跨拓扑迁移研究。

应在 **M7--M9** 加入，前提是 handover 的 matched-budget 结果和 coordination-necessity check 通过。顺序为：

1. 刚性 stylus 或 wiping puck--plate（可控几何、准静态、易构造 oracle wrench/接触）；
2. 一手持盘/工件、一手持刷/海绵的持续擦拭；
3. 最后才进入可变形海绵、清洗液和高摩擦不确定性。

TAMEn 已直接展示 dish washing，因此论文的新意不能是“首次双手刷盘子”，而应是：handover 学到的接触流表示能否在新拓扑、工具和角色结构上迁移，并能否解释/预测载荷路径。

## 5. 最关键的证据缺口

- 多数工作不报告独立训练 seeds、置信区间或显著性；物理 trial 数也常偏少。
- 很多所谓 dynamic graph 的边来自仿真、几何阈值或已知结构，而非部署观测推断。
- object OOD 很常见，但真正的 topology OOD、role swap、sensor OOD 和 embodiment OOD 往往混写。
- 很少有论文同时报告独立 F/T 真值、触觉输入和不确定性校准；因此 future wrench 评估必须明确仪器与信息依赖。
- Artifact 公开状态与论文主张常不一致；复现前必须锁定下载、license、commit 和 checkpoint。

## 6. 推荐的 M1 复现顺序

1. VTDexManip `Bimanual Hand-over`：最清晰、统计协议相对完整。
2. PhysGraph stock-main 与 corrected-bias：回答结构 token 与 bias 的真实贡献；它不是部署触觉表示。
3. T-Rex 20--100 episode 数据审计和离线 probe：若公共子集可用，这是最有价值的真实双手触觉数据源。
4. SaTA-like 和 TouchWGNN-like 轻量重实现：作为空间锚和动态图基线。
5. 只有上述链路稳定后，才实现 BiCG-Rep v0 的层级边推断与物理目标。
