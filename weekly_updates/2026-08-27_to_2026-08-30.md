## 1. 本周结论

本轮最重要的变化不是出现了一个已经闭合研究缺口的新触觉系统，而是出现了五个应加入
后续实验的更强对照维度。

1. **结构先验与生成残差应作为组合基线。** MeshPriorDiT 不是简单的“GNN 对
   Transformer”，而是用 mesh GNN 表达拓扑和抓取约束，再由 flow-matching DiT 补偿
   长程与残差效应。后续应比较 structured prior only、global residual only 与二者组合。
2. **持续接触需要显式测试松弛和漂移。** Relaxation-Aware Soft Gripper 显示，温度、
   黏弹性和接触持续时间会改变力估计；仅靠瞬时 tactile/force frame 的表示可能在长时间
   抓持中系统漂移。
3. **时序信息的强对照变得更具体。** TemporalFlow-VLA 通过训练期几何流监督执行历史，
   PredVLA 用 prediction-error inference 更新隐状态。两者都没有分布式触觉，因此适合做
   vision/proprioception temporal baseline，不能当作触觉结构缺口已关闭的证据。
4. **双手动态与跨 embodiment 世界模型继续增强。** Robot Juggling 与 CLAP 分别强化在线
   双手动力学学习和跨 embodiment 视频预测，但都没有估计跨手载荷路径或动态接触拓扑。
5. **表示需要和恢复机制共同评价。** FLARE 将 retry、reset 和在线失败监测拆开，提示后续
   不应只报告成功率，还应报告失败发现、恢复类型、恢复次数和恢复后的载荷/安全代价。

**本轮边界判断：** 新增论文中仍没有一篇同时满足“双手 + 分布式触觉 + 从部署观测推断
跨手/物体/工具的动态关系 + strict topology OOD”。这是本轮快速筛查的判断，不是全领域
的首次或唯一性声明。

## 2. 纳入活文献库的 7 篇论文

### A. 结构、动力学与持续接触

#### MeshPriorDiT

- 入口：[arXiv 2608.26766](https://arxiv.org/abs/2608.26766)
- 方法：action-conditioned mesh GNN 先给出显式 material topology 与 grasp-constraint prior，
  residual DiT 再以 flow matching 学习未被局部结构解释的全局形变。
- 论文报告：15 步 rollout、三项布料操作任务；相对 GNN-only，平均 Global MSE 降低
  43.42%，相对 DiT-DDPM 降低 75.03%，同时 Edge-strain MSE 与 GNN-only 接近。
- 边界：研究对象是布料 mesh dynamics，没有触觉传感或双手载荷转移。
- 对本项目的动作：加入 **graph prior only / residual global model only / hierarchical
  combination** 三组匹配预算比较，并分别评价全局状态误差与边/应变一致性。

#### Relaxation-Aware Multimodal Sensing of Soft Gripper

- 入口：[arXiv 2608.26622](https://arxiv.org/abs/2608.26622)；论文标注为 RSS 2026。
- 方法：可变刚度软夹爪结合机载视觉和红外热成像，用温度耦合的黏弹性表示与 physics-
  informed model 估计抓持力随时间的松弛。
- 论文报告：280 秒 force-controlled hold 中 MAE 为 0.066 N；相对 fixed-aperture 与只看
  瞬时状态的基线，误差分别降低 80% 和 95%。
- 边界：这是单夹爪软体感知/力估计，不是分布式触觉关系图。
- 对本项目的动作：增加 1/10/60/280 秒 contact-duration stress test，并记录温度、历史
  窗口、材料和重新抓持后的漂移。

### B. 双手动态、世界模型与执行历史

#### Rapid On-Robot Learning for Robot Juggling

- 入口：[arXiv 2608.26800](https://arxiv.org/abs/2608.26800)
- 方法：双手机器人用带全局 prior 的正则化 memory-based local model 在线学习抛接动力学，
  同时用 mutually reachable safe set 约束动作组合。
- 论文报告：真实机器人交互不足 5 分钟即可学习并组合五种三球 juggling pattern。
- 边界：使用机载视觉和多指手，但论文没有触觉输入主张；动态接球也不等同于同时承载阶段
  的 load-share 推断。
- 对本项目的动作：把“global prior + rapidly adapted local model”纳入物体/材料变化基线，
  并单独检查触觉是否缩短适应时间或降低掉落率。

#### CLAP

- 入口：[arXiv 2608.27406](https://arxiv.org/abs/2608.27406)；
  [官方代码与模型](https://github.com/omni-CLAP/clap)
- 方法：把末端位姿、语言和 latent action 对齐到一个 action-conditioned video world model；
  先从无标签视频学习，再做 end-effector grounding。数据/示例覆盖 DROID、Bridge、双手
  YAM 和 G1。
- Artifact：本轮已确认公开代码、checkpoint、示例数据与双手 YAM 配置入口。
- 边界：输入输出核心是视频和动作，不观察 distributed touch，也不输出 contact/load graph。
- 对本项目的动作：可作为 cross-embodiment visual prediction baseline；主张结构化触觉收益
  时，必须证明触觉在遮挡、摩擦变化、滑移或载荷转移条件下提供额外信息。

#### TemporalFlow-VLA

- 入口：[arXiv 2608.26821](https://arxiv.org/abs/2608.26821)
- 方法：训练期由 robot state、几何和标定相机构造 robot-surface temporal flow，监督两个
  temporal query；部署时不再需要该几何监督。
- 论文报告：LIBERO 平均 97.63 ± 0.26%，LIBERO-Long 为 96.60 ± 0.87%；12 项
  RoboTwin 任务 Clean/Randomized 分别为 85.5%/84.2%。历史内容和顺序干预显示二者都
  影响表现。
- 边界：训练期 grounding 是几何流，部署输入没有触觉；这些数字来自不同 benchmark，
  不与本综述其他任务横向排序。
- 对本项目的动作：加入 history content mask、history order shuffle、仅最后一帧和等长度
  无序窗口四项干预，验证性能来自时序关系而不是额外容量。

### C. 预测误差与失败恢复

#### PredVLA

- 入口：[arXiv 2608.26673](https://arxiv.org/abs/2608.26673)
- 方法：0.68M trainable parameters 的层级生成递归动力学预测视觉特征与 proprioception；
  观测只通过 prediction-error inference 修正 latent。
- 论文报告：LIBERO 短程平均成功率 86.9%，含长程任务平均 75.4%；在相同前端、数据、
  decoder 和协议下，平均成功率为参数匹配 Transformer/LSTM 的 3.7/7.4 倍。
- 关键消融：禁用 observation-driven latent correction，形成精确的 open-loop 对照。
- 边界：没有触觉输入，结果来自 LIBERO；适合作为小参数时序预测基线。
- 对本项目的动作：增加 exact open-loop ablation，并比较 prediction error 是否能预测
  contact transition、slip 或恢复触发，而不只用于 latent 更新。

#### FLARE

- 正式入口：[CVPR 2026 Open Access](https://openaccess.thecvf.com/content/CVPR2026/html/Zhao_FLARE_A_Failure-Aware_Framework_for_Autonomous_Correction_and_Recovery_in_CVPR_2026_paper.html)
- 方法：Retry 用扰动/bridging segment 纠正局部执行，Reset 用离线 MLLM 失败分析生成
  object-centric recovery skill，在线 MLLM monitor 决定继续、重试或重置。
- 边界：以视觉—语言监测为主，没有触觉关系表示；恢复技能的成功不能反推其学习到了
  载荷传播结构。
- 对本项目的动作：将 failure detection、Retry、Reset 分开计量；增加恢复触发 precision/
  recall、恢复次数、恢复后安全超限和不可恢复失败类型。

## 4. 观察名单：本轮不计入主语料

- [Active Surface-Driven Reconfigurable Gripper](https://arxiv.org/abs/2608.26883)：有价值的
  可重构夹爪硬件，但没有触觉表征、学习到的接触结构或双手协调主张。
- [Task-Space Model-Based Control of Pneumatic Soft Actuators](https://arxiv.org/abs/2608.27186)：
  主要是软体执行器自由空间 task-space 控制，与本综述的接触关系表示距离较远。
- [FlashVLA](https://arxiv.org/abs/2608.27384)：重点是 VLA 推理延迟/吞吐；暂未发现能改变
  触觉或接触结构比较的直接证据。

## 5. 立即落实到实验计划的修订

### 必增匹配基线

1. structured graph/mesh prior only、global residual model only、二者层级组合；
2. TemporalFlow 风格有序历史监督与 PredVLA 风格 prediction-error recurrent baseline；
3. vision-only cross-embodiment world model，与加入 tactile/interface token 后的等预算版本；
4. Retry/Reset failure-recovery state machine，不把恢复收益混进 representation gain。

### 必增压力测试与指标

- contact duration、temperature、viscoelastic relaxation 和历史窗口长度；
- history content mask、order shuffle、open-loop latent correction ablation；
- 物体/材料变化时的在线适应时间、掉落率和 safe-set violation；
- failure detection precision/recall、重试/重置次数、恢复后峰值载荷/形变/滑移；
- graph prior、residual correction 和二者组合的 global error 与 edge/strain consistency。
